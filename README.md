# Congo Plator ANRP Backend

Backend service built with **FastAPI** and **Python >= 3.12** for the Congo Plate ANRP project.

---

## 🚀 Tech Stack

* **Framework:** [FastAPI](https://fastapi.tiangolo.com/) (`fastapi[standard]`)
* **Language:** Python 3.12+
* **Package Management:** `uv` (recommended) or standard pip / pyproject.toml backend
